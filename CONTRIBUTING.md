# Guide de Contribution

Merci de votre intérêt pour contribuer à SUPFile !

## Structure du projet

- `backend/` : API FastAPI
- `frontend/` : Application React
- `azure/` : Configurations de déploiement Azure
- `docs/` : Documentation

## Développement local

1. Cloner le projet
2. Copier les fichiers `.env.example` vers `.env`
3. Configurer les variables d'environnement
4. Démarrer avec Docker Compose : `docker-compose up`

## Standards de code

- **Python** : PEP 8, type hints
- **TypeScript** : ESLint, Prettier
- **Commits** : Messages clairs et descriptifs
- **Tests** : Ajouter des tests pour les nouvelles fonctionnalités

## Pull Requests

1. Créer une branche depuis `main`
2. Faire vos modifications
3. Ajouter des tests si nécessaire
4. Vérifier que tout fonctionne localement
5. Créer la Pull Request avec description détaillée

## Questions

Pour toute question, ouvrir une issue sur GitHub.
